# Sprints

One-week sprints ([ADR-0001](../adr/0001-process-model.md)). Each sprint file has three parts: **Planning** (goal and committed stories), **Review** (what was demonstrated, against the acceptance criteria) and **Retrospective**.

> **How to use these records honestly.** The plan, stories, tasks and "delivered" sections describe the code that is in this repository. The *review* and *retrospective* sections are written as **drafts**: hold the actual meeting, correct what really happened, add attendees and the real date, change `Status: DRAFT` to `Status: HELD`, and commit. The commit history then shows when each record became real.
