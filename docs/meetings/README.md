# Meeting records

> **Every file here is a prepared DRAFT** with an agenda and *proposed* decisions based on the project plan. They are not minutes of meetings that already happened. For each one: hold the meeting, write down who attended and what was actually decided (change anything that differs, including decisions you reject), set the real date, change `Status: DRAFT` to `Status: HELD`, and commit. Graders look at the commit history; a record that becomes real on the day it was held is worth far more than a polished fake.
